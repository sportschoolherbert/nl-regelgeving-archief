# nl-regelgeving-archief
Downloadt Nederlandse open data (Basiswettenbestand, CVDR, Rechtspraak Open Data) in zips en zet ze in Google Drive.
Draait in GitHub Actions; bestaande zips worden overgeslagen, de workflow zet zichzelf uit als alles binnen is.

**Waar we verder gaan en de status per bron:** afgeschermde werkmap
[sportschoolherbert/nl-regelgeving-archief-werk](https://github.com/sportschoolherbert/nl-regelgeving-archief-werk)
(`VERDER.md` = open punten, `BRONNEN.md` = route en omvang per bron).

Schone startsignalen (11-11): `aanvulling.yml -f shards=avv` · `ehr.yml` (EHRM per decennium).
